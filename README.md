# Biblioteca Horizonte

## Descripción del Proyecto

Biblioteca Horizonte es una aplicación web diseñada para la consulta, exploración y selección de libros en un entorno virtual. La plataforma ofrece una interfaz clara e intuitiva que permite a los usuarios navegar por diferentes categorías literarias, visualizar recomendaciones destacadas y gestionar una selección de obras mediante un contador dinámico.

---

## Características Principales

* **Barra de Navegación:** Incluye el logotipo oficial, un formulario de inicio de sesión mediante correo electrónico y un indicador en tiempo real del número de libros seleccionados.
* **Exploración por Categorías:** Sección dedicada a la navegación por géneros como Novelas, Ciencia, Historia, Tecnología, Arte e Infantil.
* **Sección Promocional e Informativa:** Cuadro destacado con detalles institucionales e imágenes representativas de la biblioteca.
* **Catalogo de Recomendaciones:** Lista de obras sugeridas con información relevante (título, autor) y un botón de acción rápida para agregar elementos a la selección del usuario.
* **Diseño Adaptativo (Responsive Design):** Estructura adaptada mediante *media queries* para garantizar una visualización óptima en dispositivos móviles y pantallas de escritorio.

## Tecnologías Utilizadas

* **HTML5:** Marcado estructurado y semántico para el contenido de la aplicación web.
* **CSS3:** Estilizado de componentes, diseño con Flexbox y reglas `@media` para la adaptabilidad responsiva.
* **JavaScript:** Lógica de interacción y manipulación del DOM para las funciones dinámicas.

---

## Instalación y Ejecución

1. Clonar o descargar este repositorio en el equipo local.
2. Asegurar que la estructura de carpetas concuerde con la definida en la sección **Estructura del Proyecto**.
3. Abrir el archivo `index.html` en cualquier navegador web moderno (Chrome, Firefox, Edge, Safari).
